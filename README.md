# 財務管理考古題刷題系統 (含錯題複習版)

專為台大 PMBA 財務管理課程打造的線上考古題刷題與錯題複習系統。

* 🌐 **正式線上網址**：[https://p15e41008.github.io/pmba-finance-past-exams/](https://p15e41008.github.io/pmba-finance-past-exams/)

---

## 一、同學使用說明（免安裝、零門檻）

其他同學使用時**無需下載任何檔案或手動設定**：
1. 直接在手機或電腦瀏覽器點開線上網址：[https://p15e41008.github.io/pmba-finance-past-exams/](https://p15e41008.github.io/pmba-finance-past-exams/)
2. 系統會**自動從雲端下載同目錄的最新 `財務管理考古題.xlsx` 題庫**（共 514 題），並自動快取至設備本機儲存區（LocalStorage）。
3. 支援依照課程、試卷日期、章節、核心主題、高頻考題次數與關鍵字進行多維度篩選。
4. 提供「排除重複題目」、「只顯示需複習」、「只顯示尚未作答」開關。
5. 支援手機單手刷題、即時 O/X 答題回饋、詳盡解析展開與點擊放大圖表。

## 二、開發者測試指引 (Testing Guide)

在修改程式碼且尚未 Push 上線前，若要在本機進行端對端（E2E）測試，請依下列方式進行：

### 1. 電腦瀏覽器模擬手機版（最推薦、3 秒完成）

模擬「全新手機、第一次使用、無任何快取」的最快方式：

1. **啟動本機伺服器**：
   * 在專案目錄按兩下執行 `start-e2e-test.bat`，或在終端執行：
     ```bash
     python -m http.server 8080
     ```
2. **開啟無痕式視窗**：
   * 在 Chrome 或 Edge 瀏覽器按 `Ctrl + Shift + N` 開啟無痕視窗（確保 LocalStorage 完全空白乾淨）。
   * 網址輸入：`http://localhost:8080/`
3. **切換手機模擬模式**：
   * 按下鍵盤 **`F12`** 打開開發者工具。
   * 按下快速鍵 **`Ctrl + Shift + M`** 切換為行動裝置模式（Device Toolbar）。
   * 在上方裝置下拉選單切換至 **iPhone 14 Pro** 或 **Samsung Galaxy S20**（寬度約 360~393px）。
4. **檢查重點**：
   * 題庫是否自動讀取成功（共 514 題）。
   * 題目清單上方「開始練習 Selected (512)」大按鈕是否清楚可見。
   * 畫面滾動時，最下方是否常駐吸底的綠色「開始練習」懸浮條。
   * 篩選器開關文字是否排版整齊、無折斷重疊。

### 2. 手機端 Wi-Fi 真實連線測試

1. 確認手機與電腦連接在**同一個 Wi-Fi 區域網路**。
2. 雙擊 `start-e2e-test.bat`，視窗會自動偵測並顯示您電腦的區網 IP。
3. 手機開啟 Safari / Chrome 瀏覽器，輸入該網址（例如 `http://192.168.1.76:8080/`）即可實機操作測試。

## 三、版本更新紀錄 (Changelog)

* **v5 (2026/09/03 - RWD 行動裝置體驗全面升級版)**：
  * **修復題目清單工具列破版**：小螢幕自動換行適配，徹底解決「開始練習 Selected (N)」按鈕在手機畫面中被推至螢幕外不可見、全選/取消全選按鈕文字垂直被擠扁的問題。
  * **新增手機專用「底部吸底浮動操作列」（Sticky Bottom Bar）**：小螢幕滾動清單時隨時顯示已選題數與大尺寸「開始練習」按鈕，並適配 iOS Safe Area（`safe-area-inset-bottom`），絕不被 iPhone 底部橫條遮擋。
  * **修復篩選開關重疊擠壓**：開關與標籤加入 `whitespace-nowrap` 與彈性換行，防止中文字垂直擠斷與括號錯位。
  * **表格與練習模式適配**：表頭欄位設定最小寬度避免擠扁、小螢幕滑動提示、練習模式成績三欄均分卡片、上一題/下一題單手全寬按鈕支援。
* **v4**：修正「範圍選取第 N 筆到 M 筆」時先清除舊選取，確保嚴格符合指定區間。
* **v3**：新增「只顯示尚未作答題目」開關與已作答狀態持久化記錄。
* **v2**：新增單題 O/X 答題互動、對錯統計與解析展開。
* **v1**：初始版本發布。
